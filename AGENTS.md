# Project Instructions

This is the repository for Will Hewitt's personal website.

## Current Phase

Live. The site is a single landing page (`src/pages/OceanPage.tsx` and `OceanCanvas.tsx`): a photographed sunset with the name resting on the horizon, a scroll-up about block, and a 404 page. `DESIGN.md` describes an earlier typographic direction and is kept for reference only.

## Priorities

- Keep the site fast, static, readable, and easy to maintain.
- Use Vite, React, TypeScript, React Router, and plain CSS.
- Do not introduce Tailwind, shadcn/ui, CMSs, heavy animation libraries, or unnecessary dependencies.
- Use Bun for dependency installation and script execution.
- Keep components simple and semantic.
- Keep content models clean and easy to migrate to MDX later.
- Use TypeScript carefully and keep types close to the data they describe.
- Run `bun run typecheck`, `bun run lint`, and `bun run build` before finishing changes when dependencies are installed.

## Future Design Direction

The eventual site should be centred, editorial, technical, and restrained, with warm off-white backgrounds, cobalt blue accents, serif body copy, mono labels, thin rules, and strong spacing.

## Writing Direction

Use plain wording. Do not write faux-manual, overly poetic, or "aesthetic" prose.
